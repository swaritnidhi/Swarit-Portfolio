# Design System — Swarit Portfolio

## 1. Design Philosophy

The portfolio should feel:
- Professional and minimalist
- Futuristic but practical
- Interactive and visually engaging
- Personal rather than template-generated
- Clean, readable, and easy to navigate

Avoid excessive decoration, unnecessary effects, and generic design patterns.

## 2. Visual Identity

- Maintain a consistent visual language throughout the website.
- Use the existing color palette and design tokens.
- Use glass effects selectively.
- Keep backgrounds subtle and visually comfortable.
- Use accent colors to highlight important elements.
- Maintain clear contrast between text and background.

## 3. Theme System

The website must support:
- Dark mode
- Light mode

Both themes must maintain:
- Readability
- Consistent component styling
- Appropriate contrast
- Smooth theme transitions

## 4. Typography

- Use a clear and modern font system.
- Maintain a consistent heading hierarchy.
- Keep paragraph text readable.
- Avoid excessive font sizes and unnecessary text decoration.

## 5. Layout

- Maintain consistent spacing between sections.
- Use balanced alignment and whitespace.
- Keep content organized into clear sections.
- Avoid overcrowded layouts.
- Ensure the layout works on mobile, tablet, and desktop.

## 6. Components

Reusable components should maintain consistent styling.

Important components include:
- Navigation
- Hero section
- Project cards
- Skill indicators
- Buttons
- Contact form
- Theme toggle
- Interactive elements

## 7. Animation and Interaction

- Animations should be smooth and purposeful.
- Prefer subtle transitions over excessive motion.
- Interactive elements should provide clear feedback.
- Avoid unnecessary heavy animations.
- Respect reduced-motion accessibility preferences.

## 8. Responsive Design

The website must support:
- Mobile screens
- Tablets
- Desktop screens

Layouts, typography, spacing, and interactions should adapt appropriately.

## 9. Accessibility

- Use semantic HTML.
- Maintain sufficient color contrast.
- Support keyboard navigation.
- Provide visible focus indicators.
- Ensure controls have meaningful labels.
- Avoid relying only on color to communicate information.

## 10. Design Consistency

Every new feature must:
- Follow the existing design system.
- Support both themes when applicable.
- Maintain responsive behavior.
- Match the established visual identity.
- Avoid introducing inconsistent styling.

## 11. Design Quality Standard

The final interface should feel intentional, polished, modern, and distinctly personal.
